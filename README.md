# RP_QR_CC_HW — QRcode 自動清點作業系統 (Ver. 3.4.2)

文件生產力中心 — 國小作業與通知單條碼管理、雲端總表、家長專屬查詢手札與 LINE 智慧推播系統。

本專案採純前端瀏覽器架構（HTML、JavaScript、Tailwind CSS）結合選配的 Google Apps Script (GAS) 雲端試算表資料庫與 LINE Messaging API 推播引擎，無需獨立後端伺服器即可直接部署於 GitHub Pages。

---

## 🌟 核心功能總覽

- **0. 資料建置與多班級管理**：支援單一網頁切換多個班級、自動加上 `[學年期-班級]` 試算表分頁前綴、雲端自動備份與跨設備一鍵匯入還原。
- **1. 掃描與統計**：支援相機盲掃、多作業同時清點、實體震動回饋 (Haptics)、右側待掃描作業懸浮清單與個別作業即時掃描人數統計。
- **2. 雲端總表**：即時雙向同步 Google 試算表，自動套用班級分頁色彩、凍結表頭與統計報表格式化。
- **3. 浮動卷單 (PDF) & 4. 條碼匯出與列印**：支援聯絡簿、習作、試卷條碼貼紙及 Word/Excel/PDF 批次匯出。
- **5. 批改與退回 & 6. 缺交提醒單 & 7. 個人報表**：支援退回待訂正、請假（病/事/公/喪假免計入分母）及個人作業狀況報表匯出。
- **8. 家長手札與專屬查詢小卡中心 (`parent.html`)**：
  - **作業繳交狀況查詢卡 (A4 批次列印)**：提供每頁 4 / 6 / 8 張無留白高密度排版，內含放大版 QR Code、座號姓名、專屬查詢代碼、查詢/綁定雙步驟指引與導師叮嚀；**支援教師於預覽畫面直接點擊卡片文字即時編輯（全班連動同步）或透過面板自訂文字**。
  - **家長端獨立查詢手札 (`parent.html`)**：純 QR Code 掃碼登入（支援相機鏡頭與相簿照片辨識）、學生姓名個資去識別化保護（如 `王○明`）、首次進入自動詢問綁定 LINE 缺交推播、各科準時率橫向長條圖（點擊展開各作業明細）、常遲到作業排行與最近 15 筆交件足跡。
  - **LINE 官方帳號智慧推播中心**：放學後一鍵篩選當日有缺交且已綁定 LINE 之家長發送 1 對 1 缺交通知，作業全齊不打擾；一般親師對話時機器人完全靜默，輸入查詢代碼或「查詢」即時回傳最新作業狀況。

### Ver. 3.4.2 (教室離線防斷線機制、雙端專屬圖示與手機手札升級正式版) — `2026/10/20`
- **📶 教室離線防斷線機制 (Offline Queue & Automatic Resync Engine)**：
  - 離線零中斷盲掃：斷網或訊號不穩時，打卡清點與批改異動照常運作並自動存入本地離線佇列 (`rp_offline_sync_queue`)，絕不漏單。
  - 頂部連線狀態徽章：即時反映 🟢 雲端已同步（點擊測試連線）、🟡 離線中 (X 筆待傳，點擊手動補傳)、🔵 同步補傳中。
  - 恢復連線自動補傳：偵測到網路恢復自動背景補傳，並以 Apple HIG Toast 提示「✅ 雲端同步完成！已成功補傳 X 筆清點紀錄」。
- **🎨 教師端與家長端「雙端專屬分頁圖示 (Favicon)」**：皇家藍底打勾（教師清點）與森林綠底書本（家長伴讀）雙生視覺體系，內嵌向量防灰球。
- **🔒 GAS 網址安全遮罩模式（防旁窺明碼隱私保護）**：連線後網址預設星號遮罩顯示，支援一鍵切換「顯示明碼/隱藏網址」與安全預覽。
- **⏱️ 家長端手機模擬器多階段連線同步動畫**：導入 Apple HIG 流暢動畫進度卡與光束滑過動效，呈現 28% ➔ 65% ➔ 88% ➔ 100% 同步進度。
- **🛠️ 貫徹「只有教師註記遲交才是遲交，不管時間點」準則**：全面取消依時間戳記與截止日自動比對遲交，完全以教師明確登記之 `[遲交]` 註記為準，兼顧課室彈性。

### Ver. 3.4 (個資保護去識別化、Apple HIG 介面升級與可編輯小卡版) — `2026/10/17`
- **✏️ 作業繳交狀況查詢卡「零留白重排」與「教師自由編輯文字」**：
  - 小卡正式定名為**「作業繳交狀況查詢卡」**，消除卡片內多餘留白，放大 QR Code（105~130px）與學生姓名座號，整合「1. 手機掃描查詢」、「2. LINE 自動通知」與「💡 導師叮嚀」三大區塊。
  - 支援**雙軌即時編輯**：教師可直接於 A4 預覽畫面上**點擊任意卡片文字即時打字修改**（全班卡片自動同步並記憶於 `localStorage`），或透過 Tab 8 及預覽視窗頂部面板批次編輯、切換每頁密度（4/6/8 張）與一鍵恢復預設文字。
- **🛡️ 個資法保護「學生姓名去識別化」機制**：家長端網頁、手機模擬器與 LINE 自動推播訊息全面導入姓名遮罩保護（三字姓名中間字轉 `○`、兩字姓名末字轉 `○`，如「王○明」），兼顧親師辨識度與個人資料安全。
- **🔔 首次進入家長端自動引導綁定 LINE 提醒**：家長首次掃碼開啟手札且尚未綁定 LINE 時，自動彈出 Apple HIG 原生毛玻璃風格詢問視窗，引導一鍵開啟 LINE 完成自動缺交通知綁定；若已完成雲端綁定則自動隱藏橫幅與提示，並移除冗餘總繳交率指標。
- **🍎 全面導入 Apple Design & Apple HIG 設計規範**：教師端與家長端全面升級毛玻璃導覽列 (`backdrop-blur`)、彈簧物理過渡曲線、數據等寬對齊 (`tabular-nums`)、最小 `44×44pt` 觸控點擊目標、無障礙 `aria-label` 標籤，以及 `prefers-reduced-motion` 減弱動態支援；頂部導覽列 0~8 分頁優化為單行自適應不換行。
- **💬 LINE 官方帳號智慧靜默與即時成績回傳**：家長於 LINE 傳送一般親師對話時機器人完全靜默，保留純粹 1 對 1 親師溝通空間；僅於輸入專屬查詢代碼或「查詢」時秒回學生最新作業繳交摘要與含雲端參數之手札連結。
- **🎯 LINE 指定學生推播與各科作業歷次明細二階展開**：LINE 推播中心支援勾選指定缺交學生發送、單一學生「📨 單發」或對任意已綁定學生進行「📨 1對1 自訂推播」；家長手札與手機模擬器之「各科繳交狀況」支援點擊單項作業（如 `作文 75% 遲1`）再次展開歷次作業明細，清楚列出每一份作業範圍/日期與遲交、缺交、準時狀態。
- **🎨 雲端分頁配色與交件足跡精準化**：雲端試算表自動為「LINE 家長綁定名單」套用班級專屬分頁色彩；修正「最近 15 筆交件足跡」遲交判定邏輯，完全對齊教師批改狀態；修復統計表 Excel 匯出按鈕綁定。
