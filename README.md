# RP_QR_CC_HW — QRcode 自動清點作業系統 (Ver. 3.2.2 純清點作業版)

文件生產力中心 — 國小作業與通知單條碼管理、雲端總表與即時清點登記系統【純清點作業專屬分支】。

本分支為「無家長端、純粹清點作業版」，完全移除家長手札、LINE 智慧推播及查詢小卡模組，專注於教師現場日常作業收發、即時掃碼、統計總表、批改退回與缺交提醒。採純前端瀏覽器架構（HTML、JavaScript、Tailwind CSS）結合選配的 Google Apps Script (GAS) 雲端試算表資料庫，無需獨立後端伺服器即可直接部署於 GitHub Pages。

---

## 🌟 核心功能總覽 (0 ~ 7 純清點導覽分頁)

- **0. 資料建置與多班級管理**：支援單一網頁切換多個班級、自動加上 `[學年期-班級]` 試算表分頁前綴、雲端自動備份與跨設備一鍵匯入還原。
- **1. 掃描與統計**：支援相機盲掃、多作業同時清點、實體震動回饋 (Haptics)、右側待掃描作業懸浮清單與個別作業即時掃描人數統計。
- **2. 雲端總表**：即時雙向同步 Google 試算表，自動套用班級分頁色彩、凍結表頭與統計報表格式化。
- **3. 浮動卷單 (PDF) & 4. 條碼匯出與列印**：支援聯絡簿、習作、試卷條碼貼紙及 Word/Excel/PDF 批次匯出（無家長小卡干擾）。
- **5. 批改與退回 & 6. 缺交提醒單 & 7. 個人報表**：支援退回待訂正、請假（病/事/公/喪假免計入分母）及個人作業狀況報表匯出。
