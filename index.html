Ver. 1.2 (重大更新) 2026/08
  • Word 分頁保護機制：優化全班條碼匯出表格，全面啟用「禁止跨頁斷行 (cantSplit)」，確保標籤不會被切斷；自動跨頁重複標題列，作業過多時自動橫向 (Landscape) 排版。
  • 互動流程優化：全班條碼匯出改為點擊「預覽條碼對照表」後才生成，避免設定中頻繁轉圈；加入「全選 / 全不選」快速按鈕。
  • 匯出格式升級：新增 Excel 格式 (.xlsx) 匯出功能，並將「學生防偽代碼清單」集中至同一頁籤管理。
  • 操作介面翻新：「Word條碼」更名為「全班條碼匯出」，「批次標籤」更名為「部分學生條碼匯出」，並新增本「更新紀錄」面板。
  • 系統穩定性提升：修復雲端匯入背景腳本當機問題；新增灰色防偽浮水印（不遮擋介面）。

  • 系統正式上線：提供班級學生資料建置與 QR Code 條碼生成。
  • 支援固定簿冊(PDF)、浮動卷單(PDF)、Word 條碼與批次標籤列印。

        🚀 Google 試算表自動連線設定教學

        為了取得那串神祕的「網頁應用程式網址」，請您跟著以下 3 個簡單的步驟操作：

        第一步：建立試算表與開啟 Apps Script

        1. 請到您的 Google 雲端硬碟，建立一個全新的 Google 試算表。
        2. 點擊上方選單的 「擴充功能」 -> 「Apps Script」。
        3. 畫面上會開啟一個新的程式碼編輯器網頁。

        第二步：貼上接收資料的程式碼

        請將原本編輯器裡面的預設程式碼 function myFunction() { } 全部刪除，並完全複製貼上下方這段程式碼：

        function doPost(e) {
  try {
    var payload = JSON.parse(e.postData.contents);
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    
    if (payload.action === 'ping') {
      return ContentService.createTextOutput(JSON.stringify({status: 'success'})).setMimeType(ContentService.MimeType.JSON);
    }
    
    if (payload.action === 'upload_records' || payload.action === 'full_sync') {
      var records = payload.records || [];
      if (records.length > 0) {
        var logSheet = ss.getSheetByName("所有掃描紀錄");
        if (!logSheet) {
          logSheet = ss.insertSheet("所有掃描紀錄");
          logSheet.appendRow(["打卡時間", "科目", "作業名稱", "範圍", "學生姓名", "狀態"]);
          logSheet.setFrozenRows(1);
        }
        records.forEach(function(row) {
          logSheet.appendRow([row.timestamp, row.subject, row.taskName, row.range, row.studentName, row.status]);
        });
      }
      
      if (payload.action === 'full_sync' && payload.sheets) {
        payload.sheets.forEach(function(sheetObj) {
          var name = sheetObj.name;
          var data = sheetObj.data;
          if (data && data.length > 0) {
            var targetSheet = ss.getSheetByName(name);
            if (!targetSheet) { targetSheet = ss.insertSheet(name); }
            targetSheet.clear();
            targetSheet.getRange(1, 1, data.length, data[0].length).setValues(data);
            
            // 設定凍結窗格 (前三列為表頭：作業名稱、應繳交日期、範圍)
            targetSheet.setFrozenRows(3);
            targetSheet.setFrozenColumns(1);
            
            // 美化表頭
            targetSheet.getRange(1, 1, 3, data[0].length).setFontWeight("bold").setBackground("#f3f4f6");
            
            // 讓「缺交」變紅字
            var rule = SpreadsheetApp.newConditionalFormatRule().whenTextEqualTo("缺交").setFontColor("#ef4444").build();
            var rules = targetSheet.getConditionalFormatRules();
            rules.push(rule);
            targetSheet.setConditionalFormatRules(rules);
          }
        });
      }
      return ContentService.createTextOutput(JSON.stringify({"status": "success"})).setMimeType(ContentService.MimeType.JSON);
    }
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({"status": "error", "message": error.toString()})).setMimeType(ContentService.MimeType.JSON);
  }
}

        貼上後，記得點擊上方的 「💾 儲存專案」 按鈕（磁碟片圖示）。

        第三步：發布並取得專屬網址

        1. 點擊編輯器右上角的 「部署」 -> 「新增部署作業」。
        2. 點擊左上角的 「齒輪 ⚙️」圖示，選擇 「網頁應用程式 (Web App)」。
        3. 填寫設定：
          • 說明：隨便填寫（例如：作業掃描接收器）
          • 執行身分：請務必選擇 「我 (您自己的 email)」
          • 誰可以存取：請務必選擇 「所有人 (Anyone)」 (注意：如果您選錯了，網頁會出現 CORS 阻擋錯誤而連線失敗)
        4. 點擊 「部署」。
          (若出現安全警告，請點擊「審查權限」-> 選擇帳號 -> 左下角的「進階」->「前往未經安全認證的專案」->「允許」)
        5. 成功後，複製畫面上以 https://script.google.com/.../exec 結尾的 「網頁應用程式網址」，並貼回本系統儲存即可！
